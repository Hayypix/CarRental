СИСТЕМА УПРАВЛЕНИЯ ПРОКАТОМ АВТОМОБИЛЕЙ (CarRental)
Курсовой проект: C#, Windows Forms, .NET Framework 4.8, база данных SQLite

ЗАПУСК
1. Открыть файл CarRental.sln в Visual Studio 2019/2022
   (нужна рабочая нагрузка "Разработка классических приложений .NET").
2. При первой сборке Visual Studio сама скачает пакет System.Data.SQLite
   из NuGet (нужно подключение к интернету).
3. Запустить проект клавишей F5.
4. Логин: admin, пароль: admin.

БАЗА ДАННЫХ
Файл базы carrent.db создаётся автоматически при первом запуске
(лежит рядом с CarRental.exe в папке bin\Debug).
Чтобы сбросить данные - удалить этот файл и запустить программу снова.
Скрипт создания базы со стартовыми данными - в файле database.sql.

ВОЗМОЖНОСТИ
- вход по логину и паролю
- справочник автомобилей (добавление, изменение, удаление, поиск)
- справочник клиентов (добавление, изменение, удаление, поиск)
- оформление проката: выбор свободного автомобиля, клиента и сроков,
  автоматический расчёт стоимости
- возврат автомобиля: расчёт итоговой суммы по фактическому сроку
- у автомобиля статусы "Свободен" / "В аренде"
- удалить автомобиль или клиента, по которым есть договоры, нельзя

СТРУКТУРА ПРОЕКТА
LoginForm          - форма входа
MainForm           - главное окно с меню
CarsForm           - список автомобилей
CarEditForm        - добавление/изменение автомобиля
ClientsForm        - список клиентов
ClientEditForm     - добавление/изменение клиента
RentalsForm        - договоры проката
RentalForm         - оформление нового проката
Database.cs        - подключение к базе и её создание
database.sql       - скрипт создания базы (для отчёта)
